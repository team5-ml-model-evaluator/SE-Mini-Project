Client Evaluation Guide

{% if comparison.task == "classification" %}
  • Accuracy: Percentage of predictions that matched the actual outcome (higher is better).
  • Precision: How reliably positive predictions indicate actual positive instances (higher is better).
  • Recall: Proportion of actual positive instances successfully captured by the model (higher is better).
  • F1-Score: Harmonic balance between precision and recall, especially valuable for skewed or imbalanced data.
{% else %}
  • MAE (Mean Absolute Error): Average absolute difference between predicted and actual numbers in the target's original units (lower is better).
  • RMSE (Root Mean Squared Error): Quadratic error metric penalizing larger mistakes more heavily (lower is better).
  • R² (Coefficient of Determination): Proportion of variance explained by the model; 1.0 represents a perfect fit (higher is better).
{% endif %}
